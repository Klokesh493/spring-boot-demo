# Spring Boot Demo runbook

## What the project does

A developer exploring the upstream Spring Boot examples needs a small module that traces an HTTP request from routing to response.

See the [architecture and data flow](ARCHITECTURE.md) and [project case study](CASE_STUDY.md).

## Run from a clean checkout

Follow the [Hello World module walkthrough](CASE_STUDY.md) with its Java and Maven prerequisites.

The [case study](CASE_STUDY.md) describes the expected path and the scope of verification.

Start with the upstream Hello World module, inspect its Java and Maven versions, and verify the HTTP route against that module.
